Regression.m: Is a self‑contained MATLAB/Octave script for comparative model fitting and diagnostic analysis of a univariate regression problem (example dataset embedded). It fits five candidate models (Linear, Log‑Log/power, Exponential, Hyperbola, and a nonlinear Power fit), computes goodness‑of‑fit and model‑selection metrics (SSE, 𝑅2, AIC, AICc, BIC), estimates parameter uncertainty via residual bootstrap, and evaluates predictive performance with 𝑘‑fold cross‑validation (CV RMSE). The script also produces diagnostic plots (data scatter with best fit, residuals vs fitted, QQ plot, Cook’s distances, residual histogram, CV RMSE bar chart), runs an influence analysis with a permutation test for influential observations, and reports bootstrap confidence intervals and permutation p‑values.
